

\# PayPulse



AI-Powered Payment Intelligence Platform.



A microservices-based payment processing simulation

built using Java, Spring Boot, React, PostgreSQL,

Redis, RabbitMQ, and Spring AI.



\## Main Features



\- Merchant authentication

\- Simulated payment processing

\- Idempotent payment requests

\- Refund processing

\- Double-entry ledger

\- Asynchronous payment events

\- AI-powered payment failure investigation

\- AI-powered merchant analytics

\- Redis caching and rate limiting



\## Architecture



Three core backend services:



1\. Payment Service

2\. Bank Simulator Service

3\. Intelligence Service



API Gateway and React frontend provide access

to the platform.
